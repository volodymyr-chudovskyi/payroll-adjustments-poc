# Payroll Earning Line Adjustments — Proof of Concept

A domain model for the history of manual adjustments to an automatically calculated earning line.

## Quick start

With Docker:

```sh
docker compose run --rm app composer install
docker compose run --rm app composer check
docker compose run --rm app composer demo
```

With local PHP 8.5:

```sh
composer install
composer check
composer demo
```

_Full documentation is written in the final step of development — see commit history._
